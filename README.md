# Hospital Management System — Demo Project

This repository contains an older PHP/MySQL hospital-management application and a static portfolio showcase in [`docs/`](docs/). The showcase can be published with GitHub Pages. It is fictional and does not collect or store data.

**Important:** Do not publish the PHP/MySQL app as a live healthcare service. It contains legacy security and access-control patterns, demo identities/passwords in the SQL dump, and payment schema fields that should not be used to store card security codes. Do not enter real patient, symptom, password, or payment information. The AI-related pages are a non-clinical demo, not validated medical AI.

For the safer public preview, see [`docs/README.md`](docs/README.md). GitHub Pages can serve that static preview but cannot run the PHP application or its MySQL database. The source code is available for learning and review; comprehensive testing and security review are still required before deploying the backend anywhere.
